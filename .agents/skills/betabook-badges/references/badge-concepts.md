# Candidate badge concepts

These are starting points from the Betabook badge brainstorm. Adapt motifs to the user's request; thresholds are provisional. Keep numbers and names in UI labels, not inside artwork.

## Keep the set varied

Spread motifs across gear, maps, hands, and rocks. Use the same visual grammar without making every badge a face, mountain, medal, or star. Color alone must not distinguish achievements. Grade or tier variants should preserve the core motif, with their exact milestone supplied by the interface.

## Example invocation

“Use $betabook-badges to generate Sandbagger, Never Gets Old, and Explorer as a matching set for profile display. Keep the humor dry and the drawings simple.”
